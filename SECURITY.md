# Security Policy

This is Kettle Edition, an unofficial build of qBittorrent. Report problems in the Kettle Edition changes (user
accounts, roles, the activity log, the updater) here, not to the qBittorrent project.

Please do not report security vulnerabilities through public GitHub issues. Use this repository's private
vulnerability reporting (Security tab > Report a vulnerability).

Please include the type of issue, steps to reproduce it, and what an attacker could do with it.

Only the latest release is supported. For flaws that are also in official qBittorrent 5.3.0, report them to
the [qBittorrent project](https://github.com/qbittorrent/qBittorrent/security/policy) as well.
